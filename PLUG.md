# Canopy

An Obsidian-style sidebar for SilverBullet: a collapsible folder tree with
per-page icons and right-click create / rename / delete.

See the [README](https://github.com/sud0pls/canopy) for full configuration.

```lua
config.set {
  plugs = {
    "github:sud0pls/canopy/canopy.plug.js"
  }
}
```
